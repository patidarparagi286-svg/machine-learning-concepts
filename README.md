# machine-learning-concepts
Practical implementations of core Machine Learning algorithms, feature engineering techniques.
## 📌 Repository Contents

| Notebook File | Category | Description |
| :--- | :--- | :--- |
| **`iris_kmean.ipynb`** | Unsupervised Learning | K-Means clustering implementation on the Iris dataset, including Standard Scaling, WCSS Elbow Method analysis, and Silhouette Scoring. |
| **`tips_one_hot_encode(regr).ipynb`** | Regression / Preprocessing | Linear regression model built using One-Hot Encoding to handle categorical features in the Tips dataset. |
| **`Decision_tree_with_homeprice_update.ipynb`** | Supervised Learning | Decision Tree classifier and regressor models for home price estimation. |
| **`LabelEncoding(regr).ipynb`** | Feature Engineering | Application of Label Encoding techniques on categorical variables for regression models. |
| **`insurance_(logistic_regression).ipynb`** | Classification | Binary classification model using Logistic Regression to predict insurance buyers. |
| **`cgpa_placement(classi).ipynb`** | Classification | Classification analysis predicting student job placement outcomes based on CGPA. |
| **`Loan_approval_pipeline.ipynb`** | ML Pipelines | End-to-end machine learning pipeline for automated loan approval prediction. |
